# Nova Store — IMPORTANT: How to Run

## White screen? You must use these commands:

```bash
cd nova-store
npm install
npm run dev
```

Then open the URL Vite shows (usually http://localhost:5173)

**DO NOT** open index.html directly in the browser. That will always show a white screen.

## What this project includes

- 16 products
- Full cart + filters + checkout
- 3D mouse-tilt on product cards (Framer Motion)
- Floating animated shapes on hero
- Scroll-based page transitions
- Search overlay
- Dark / light mode toggle
- Toast notifications
- Color grading + premium minimal design

## Requirements

- Node.js 18+ installed
- Internet (for product images from Unsplash)

## If still white screen

1. Delete node_modules and package-lock.json
2. Run: npm install
3. Run: npm run dev
4. Open browser console (F12) and send me the red error message
